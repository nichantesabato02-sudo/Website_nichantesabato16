# Nichante Sabato Personal Website

This is a static website that can be hosted with GitHub Pages.

## Publish with GitHub Pages

1. Upload the contents of this folder to a GitHub repository.
2. Make sure the default branch is named `main`.
3. Open the repository's **Settings > Pages**.
4. Under **Build and deployment**, choose **GitHub Actions**.
5. Push a change or run the **Deploy to GitHub Pages** workflow from the **Actions** tab.

The website entry point is `index.html`. The Flask and Python files are not required for GitHub Pages hosting.
